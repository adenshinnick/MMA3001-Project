rocket6dof.aerodynamics

Aerodynamic model: normal force, centre of pressure, drag and moments.

Normal force and centre of pressure (CP)

Barrowman's method (Barrowman, 1967), in the form used by OpenRocket (Niskanen, 2009). Each component produces a normal-force slope C_N_alpha [1/rad] acting at its own CP:

  • Nose cone: C_N_alpha = 2 for any shape. Its CP is at L - V/A_base from the tip (V = nose volume, A_base = base area). For an ellipsoid this is L/3.
  • Body tube: no normal force at small angles (its cross-section is constant).
  • Fins: a lifting-surface formula with a compressibility factor beta = sqrt(1 - M^2) and a body-interference factor 1 + r/(s + r).

The rocket's CP is the C_N_alpha-weighted average of the component CPs.

Drag

A drag build-up in the style of OpenRocket: skin friction on the wetted area, pressure drag of the blunt fin edges, and base drag. The friction coefficient is the larger of the smooth-turbulent and roughness-limited values. These formulas are for subsonic flight, so drag is only computed up to Mach 0.8 (MACH_MAX); above that the code stops with an error instead of extrapolating.

Frames and signs

Body x points out through the nose. Stations (positions along the rocket) are measured aft from the nose tip. The air-relative velocity in body axes is v_air = R(q)^T (v - wind).

 47class Geometry:
 48    """External shape of a single-stage rocket with one fin set.
 49
 50    Attributes
 51    ----------
 52    diameter : float
 53        Body diameter, also the reference length [m].
 54    length : float
 55        Total length, nose tip to base [m].
 56    nose_shape : str
 57        ``"ellipsoid"``, ``"conical"`` or ``"ogive"`` (tangent ogive).
 58    nose_length : float
 59        Nose cone length [m].
 60    fin_count : int
 61        Number of fins (3 or more).
 62    root_chord, tip_chord, span, sweep : float
 63        Fin root chord, tip chord, span (root to tip) and leading-edge sweep
 64        length (root leading edge to tip leading edge, along the axis) [m].
 65    fin_thickness : float
 66        Fin thickness [m].
 67    fin_station : float
 68        Station of the fin root leading edge [m].
 69    roughness : float
 70        Surface roughness height [m] (OpenRocket "regular paint" = 60e-6).
 71    lug_count : int
 72        Number of launch lugs (0 allowed).
 73    lug_radius, lug_length : float
 74        Launch lug outer radius and length [m].
 75
 76    Raises
 77    ------
 78    ValueError
 79        If any dimension is not physical; the message names the field.
 80    """
 81
 82    diameter: float
 83    length: float
 84    nose_shape: str
 85    nose_length: float
 86    fin_count: int
 87    root_chord: float
 88    tip_chord: float
 89    span: float
 90    sweep: float
 91    fin_thickness: float
 92    fin_station: float
 93    roughness: float = 60e-6
 94    lug_count: int = 0
 95    lug_radius: float = 0.0
 96    lug_length: float = 0.0
 97
 98    def __post_init__(self):
 99        positive = ["diameter", "length", "nose_length", "root_chord", "span",
100                    "fin_thickness", "roughness"]
101        for name in positive:
102            if not getattr(self, name) > 0.0:
103                raise ValueError(f"geometry field '{name}' must be > 0, got {getattr(self, name)}")
104        for name in ["tip_chord", "sweep", "lug_radius", "lug_length"]:
105            if not getattr(self, name) >= 0.0:
106                raise ValueError(f"geometry field '{name}' must be >= 0, got {getattr(self, name)}")
107        if self.nose_shape not in NOSE_SHAPES:
108            raise ValueError(f"geometry field 'nose_shape' must be one of {NOSE_SHAPES}, "
109                             f"got '{self.nose_shape}'")
110        if int(self.fin_count) != self.fin_count or self.fin_count < 3:
111            raise ValueError(f"geometry field 'fin_count' must be a whole number >= 3, "
112                             f"got {self.fin_count}")
113        if not self.nose_length < self.length:
114            raise ValueError("geometry field 'nose_length' must be shorter than 'length'")
115        if not self.fin_station + self.root_chord <= self.length + 1e-9:
116            raise ValueError("fins extend past the base: check 'fin_station' and 'root_chord'")

118    # Derived quantities. cached_property computes each one once, the first
119    # time it is used, so the right-hand side f(t, x) does not redo them.
120
121    @cached_property
122    def radius(self):
123        """Body radius [m]."""
124        return 0.5 * self.diameter
125
126    @cached_property
127    def reference_area(self):
128        """Reference area, the body cross-section pi r^2 [m^2]."""
129        return pi * self.radius**2
130
131    @cached_property
132    def fin_area(self):
133        """Planform area of one fin [m^2]."""
134        return 0.5 * (self.root_chord + self.tip_chord) * self.span
135
136    @cached_property
137    def fin_mac(self):
138        """Mean aerodynamic chord of one trapezoidal fin [m]."""
139        a, b = self.root_chord, self.tip_chord
140        return (2.0 / 3.0) * (a + b - a * b / (a + b))
141
142    @cached_property
143    def fin_midchord_cos(self):
144        """Cosine of the mid-chord sweep angle [-]."""
145        dx = self.sweep + 0.5 * self.tip_chord - 0.5 * self.root_chord
146        return self.span / sqrt(self.span**2 + dx**2)
147
148    @cached_property
149    def fin_le_cos2(self):
150        """cos^2 of the leading-edge sweep angle [-]."""
151        return self.span**2 / (self.span**2 + self.sweep**2)
152
153    @cached_property
154    def nose_cp(self):
155        """Station of the nose cone's CP [m] (Barrowman: L - V/A_base)."""
156        fraction = {"ellipsoid": 1.0 / 3.0, "conical": 2.0 / 3.0, "ogive": 0.466}
157        return fraction[self.nose_shape] * self.nose_length
158
159    @cached_property
160    def fin_cp(self):
161        """Station of the fin set's CP [m] (Barrowman's subsonic formula)."""
162        a, b, m = self.root_chord, self.tip_chord, self.sweep
163        x_from_root_le = m * (a + 2.0 * b) / (3.0 * (a + b)) + (a + b - a * b / (a + b)) / 6.0
164        return self.fin_station + x_from_root_le
165
166    @cached_property
167    def wetted_area_body(self):
168        """Wetted area of the nose cone plus body tube [m^2], by numerical integration."""
169        L, R = self.nose_length, self.radius
170        x = np.linspace(0.0, L, 2001)
171        r = nose_radius(self.nose_shape, x, L, R)
172        drdx = np.gradient(r, x)
173        nose = np.trapezoid(2.0 * pi * r * np.sqrt(1.0 + drdx**2), x)
174        return float(nose) + 2.0 * pi * R * (self.length - L)
175
176    @cached_property
177    def fineness_ratio(self):
178        """Length divided by diameter [-]."""
179        return self.length / self.diameter
180
181    @cached_property
182    def nose_joint_sin2(self):
183        """sin^2 of the angle where the nose meets the body (0 for smooth shapes)."""
184        if self.nose_shape == "conical":
185            return self.radius**2 / (self.radius**2 + self.nose_length**2)
186        return 0.0

189def nose_radius(shape, x, length, radius):
190    """Radius of a nose cone at distance ``x`` from the tip [m].
191
192    Parameters
193    ----------
194    shape : str
195        One of ``NOSE_SHAPES``.
196    x : numpy.ndarray
197        Distances from the tip, 0 to ``length`` [m].
198    length, radius : float
199        Nose length and base radius [m].
200
201    Returns
202    -------
203    numpy.ndarray
204    """
205    if shape == "ellipsoid":
206        return radius * np.sqrt(np.clip(1.0 - ((length - x) / length) ** 2, 0.0, None))
207    if shape == "conical":
208        return radius * x / length
209    if shape == "ogive":
210        rho = (radius**2 + length**2) / (2.0 * radius)   # radius of the ogive arc
211        return np.sqrt(np.clip(rho**2 - (length - x) ** 2, 0.0, None)) + radius - rho
212    raise ValueError(f"unknown nose shape '{shape}'")

218                         f"0 to {MACH_MAX}")

221def fin_normal_force_slope(geom, mach):
222    """Normal-force slope of the whole fin set, C_N_alpha [1/rad].
223
224    One fin (OpenRocket form of Diederich's formula):
225
226        C_N_alpha_1 = 2 pi (s^2 / A_ref) / (1 + sqrt(1 + (beta s^2 / (A_fin cos G))^2))
227
228    with s the span, A_fin one fin's area, G the mid-chord sweep angle and
229    beta = sqrt(1 - M^2). For 3 or more equally spaced fins the set gives
230    N/2 times one fin. The body adds lift to the fins: factor 1 + r/(s + r).
231    At M = 0 this equals Barrowman's original fin formula.
232
233    Parameters
234    ----------
235    geom : Geometry
236    mach : float
237        Mach number, 0 to ``MACH_MAX``.
238
239    Returns
240    -------
241    float
242    """
243    _check_mach(mach)
244    beta = sqrt(1.0 - mach**2)
245    s = geom.span
246    one_fin = (2.0 * pi * s**2 / geom.reference_area) / (
247        1.0 + sqrt(1.0 + (beta * s**2 / (geom.fin_area * geom.fin_midchord_cos)) ** 2))
248    interference = 1.0 + geom.radius / (s + geom.radius)
249    return 0.5 * geom.fin_count * one_fin * interference

252def normal_force_slope_and_cp(geom, mach):
253    """Total normal-force slope [1/rad] and CP station [m] of the rocket.
254
255    Parameters
256    ----------
257    geom : Geometry
258    mach : float
259        Mach number, 0 to ``MACH_MAX``.
260
261    Returns
262    -------
263    cn_alpha : float
264        Normal-force slope of the whole rocket, per radian.
265    x_cp : float
266        Station of the centre of pressure, aft of the nose tip [m].
267    """
268    cn_nose = 2.0
269    cn_fins = fin_normal_force_slope(geom, mach)
270    cn_alpha = cn_nose + cn_fins
271    x_cp = (cn_nose * geom.nose_cp + cn_fins * geom.fin_cp) / cn_alpha
272    return cn_alpha, x_cp

275def stability_margin(x_cp, x_cg, diameter):
276    """Static stability margin in calibres: (x_cp - x_cg) / d [-].
277
278    Positive means the CP is behind the CG, so the rocket turns into the wind
279    (statically stable). About 1 calibre or more is the usual rule of thumb.
280    """
281    return (x_cp - x_cg) / diameter

284def critical_reynolds(roughness, length):
285    """Reynolds number above which friction is set by surface roughness [-]."""
286    return 51.0 * (roughness / length) ** -1.039

289def skin_friction_coefficient(reynolds, mach, roughness, length):
290    """Skin-friction coefficient C_f, compressibility-corrected [-].
291
292    Fully turbulent flow is assumed (Niskanen 2009, eqs 3.79-3.84):
293
294    - smooth turbulent: C_f = 1 / (1.50 ln Re - 5.6)^2, or 1.48e-2 if Re < 1e4
295    - roughness-limited: C_f = 0.032 (roughness / length)^0.2
296    - subsonic compressibility factor (1 - 0.1 M^2) on both
297
298    The larger of the two values is used, as OpenRocket does.
299
300    Parameters
301    ----------
302    reynolds : float
303        Reynolds number based on rocket length [-], >= 0.
304    mach : float
305        Mach number [-].
306    roughness : float
307        Surface roughness height [m].
308    length : float
309        Rocket length [m].
310
311    Returns
312    -------
313    float
314    """
315    if reynolds < 1.0e4:
316        cf_smooth = 1.48e-2
317    else:
318        cf_smooth = 1.0 / (1.50 * log(reynolds) - 5.6) ** 2
319    cf_rough = 0.032 * (roughness / length) ** 0.2
320    return max(cf_smooth, cf_rough) * (1.0 - 0.1 * mach**2)

323def drag_breakdown(geom, mach, reynolds):
324    """Zero-angle-of-attack drag coefficient, split into its parts.
325
326    All coefficients use the body cross-section as reference area.
327
328    Parameters
329    ----------
330    geom : Geometry
331    mach : float
332        Mach number, 0 to ``MACH_MAX``.
333    reynolds : float
334        Reynolds number based on rocket length [-].
335
336    Returns
337    -------
338    dict
339        ``"friction"``, ``"fin_pressure"``, ``"nose_pressure"``, ``"base"``
340        and ``"total"`` [-].
341    """
342    _check_mach(mach)
343    A = geom.reference_area
344    cf = skin_friction_coefficient(reynolds, mach, geom.roughness, geom.length)
345
346    # Skin friction. The body term is scaled up for its thickness (fineness
347    # ratio f_B) and the fin term for theirs (thickness t over chord).
348    body = (1.0 + 1.0 / (2.0 * geom.fineness_ratio)) * geom.wetted_area_body
349    fins = (1.0 + 2.0 * geom.fin_thickness / geom.fin_mac) * 2.0 * geom.fin_count * geom.fin_area
350    lugs = geom.lug_count * 2.0 * pi * geom.lug_radius * geom.lug_length
351    friction = cf * (body + fins + lugs) / A
352
353    # Square fin edges: the leading edge stops the flow (stagnation pressure,
354    # reduced by sweep) and the trailing edge leaves a low-pressure wake.
355    q_stag = 1.0 + mach**2 / 4.0 + mach**4 / 40.0     # stagnation / dynamic pressure
356    base_cd = 0.12 + 0.13 * mach**2                    # base-drag coefficient, M < 1
357    leading = 0.85 * q_stag * geom.fin_le_cos2
358    fin_frontal = geom.fin_count * geom.fin_thickness * geom.span
359    fin_pressure = (leading + base_cd) * fin_frontal / A
360
361    nose_pressure = 0.8 * geom.nose_joint_sin2         # 0 for smooth nose shapes
362    base = base_cd                                     # whole base area = A here
363
364    total = friction + fin_pressure + nose_pressure + base
365    return {"friction": friction, "fin_pressure": fin_pressure,
366            "nose_pressure": nose_pressure, "base": base, "total": total}

404class DragTable:
405    """Drag coefficient tabulated against Mach number.
406
407    Values between table points come from monotone cubic (PCHIP)
408    interpolation, which follows the data without overshooting. Mach numbers
409    outside the table raise an error: nothing is extrapolated.
410
411    Parameters
412    ----------
413    mach : array_like
414        Mach numbers, strictly increasing.
415    cd : array_like
416        Drag coefficient at each Mach number, all > 0.
417
418    Raises
419    ------
420    ValueError
421        If the table is too short, not increasing, or has non-positive values.
422    """
423
424    def __init__(self, mach, cd):
425        mach = np.asarray(mach, dtype=float)
426        cd = np.asarray(cd, dtype=float)
427        if mach.ndim != 1 or mach.size < 2 or mach.size != cd.size:
428            raise ValueError("need matching 1-D arrays with at least 2 points")
429        if np.any(np.diff(mach) <= 0.0):
430            raise ValueError("Mach numbers must be strictly increasing")
431        if np.any(cd <= 0.0) or not np.all(np.isfinite(cd)):
432            raise ValueError("drag coefficients must be finite and > 0")
433        self.mach = mach
434        self.cd = cd
435        self._interp = PchipInterpolator(mach, cd, extrapolate=False)
436
437    def __call__(self, mach, reynolds=None):
438        """Drag coefficient at ``mach`` [-] (``reynolds`` is ignored)."""
439        if not self.mach[0] <= mach <= self.mach[-1]:
440            raise ValueError(f"Mach {mach:.3f} is outside the drag table "
441                             f"({self.mach[0]:.3f} to {self.mach[-1]:.3f})")
442        return float(self._interp(mach))

445def aerodynamic_loads(geom, drag_model, v_air, rho, sound_speed, viscosity, x_cg, omega):
446    """Aerodynamic force and moment on the rocket, in body axes.
447
448    Parameters
449    ----------
450    geom : Geometry
451    drag_model : callable
452        ``drag_model(mach, reynolds)`` returning C_D.
453    v_air : numpy.ndarray
454        Velocity of the rocket relative to the air, body axes [m/s].
455    rho : float
456        Air density [kg/m^3].
457    sound_speed : float
458        Speed of sound [m/s].
459    viscosity : float
460        Dynamic viscosity of air [Pa s].
461    x_cg : float
462        Station of the current CG [m].
463    omega : numpy.ndarray
464        Body angular velocity [rad/s].
465
466    Returns
467    -------
468    force : numpy.ndarray
469        Aerodynamic force, body axes [N].
470    moment : numpy.ndarray
471        Aerodynamic moment about the CG, body axes [N m].
472    mach : float
473        Mach number [-].
474
475    Notes
476    -----
477    - Drag acts opposite ``v_air`` and passes through the CG.
478    - Normal force C_N = C_N_alpha sin(alpha) acts at the CP, at right angles
479      to the body axis, opposite the cross-flow. Linear (Barrowman) theory,
480      so it is only accurate for small angles of attack (below about 10 deg).
481    - Pitch damping: rotating at rate w adds a local cross-flow w * d at
482      distance d from the CG, so each component (nose, fins) contributes
483      -q A C_N_alpha_k d_k^2 w / V.
484    - No roll moments: the fins have no cant.
485    """
486    speed = sqrt(v_air[0] ** 2 + v_air[1] ** 2 + v_air[2] ** 2)
487    zero = np.zeros(3)
488    if speed < 1e-9:
489        return zero, zero.copy(), 0.0
490
491    mach = speed / sound_speed
492    reynolds = rho * speed * geom.length / viscosity
493    q_area = 0.5 * rho * speed**2 * geom.reference_area   # dynamic pressure x area [N]
494
495    force = -q_area * drag_model(mach, reynolds) * v_air / speed
496
497    cross = sqrt(v_air[1] ** 2 + v_air[2] ** 2)            # cross-flow speed [m/s]
498    cn_fins = fin_normal_force_slope(geom, mach)
499    moment = np.zeros(3)
500    if cross > 1e-12:
501        alpha = atan2(cross, v_air[0])                     # total angle of attack [rad]
502        cn_alpha = 2.0 + cn_fins
503        x_cp = (2.0 * geom.nose_cp + cn_fins * geom.fin_cp) / cn_alpha
504        normal = q_area * cn_alpha * sin(alpha)            # size of normal force [N]
505        f_normal = np.array([0.0, -normal * v_air[1] / cross, -normal * v_air[2] / cross])
506        force = force + f_normal
507        arm = np.array([x_cg - x_cp, 0.0, 0.0])            # CG to CP, body axes [m]
508        moment = cross3(arm, f_normal)
509
510    # Pitch and yaw damping (body y and z rates only).
511    damping = (q_area / speed) * (2.0 * (geom.nose_cp - x_cg) ** 2
512                                  + cn_fins * (geom.fin_cp - x_cg) ** 2)
513    moment[1] -= damping * omega[1]
514    moment[2] -= damping * omega[2]
515    return force, moment, mach

def drag_breakdown(geom, mach, reynolds): 
324def drag_breakdown(geom, mach, reynolds):
325    """Zero-angle-of-attack drag coefficient, split into its parts.
326
327    All coefficients use the body cross-section as reference area.
328
329    Parameters
330    ----------
331    geom : Geometry
332    mach : float
333        Mach number, 0 to ``MACH_MAX``.
334    reynolds : float
335        Reynolds number based on rocket length [-].
336
337    Returns
338    -------
339    dict
340        ``"friction"``, ``"fin_pressure"``, ``"nose_pressure"``, ``"base"``
341        and ``"total"`` [-].
342    """
343    _check_mach(mach)
344    A = geom.reference_area
345    cf = skin_friction_coefficient(reynolds, mach, geom.roughness, geom.length)
346
347    # Skin friction. The body term is scaled up for its thickness (fineness
348    # ratio f_B) and the fin term for theirs (thickness t over chord).
349    body = (1.0 + 1.0 / (2.0 * geom.fineness_ratio)) * geom.wetted_area_body
350    fins = (1.0 + 2.0 * geom.fin_thickness / geom.fin_mac) * 2.0 * geom.fin_count * geom.fin_area
351    lugs = geom.lug_count * 2.0 * pi * geom.lug_radius * geom.lug_length
352    friction = cf * (body + fins + lugs) / A
353
354    # Square fin edges: the leading edge stops the flow (stagnation pressure,
355    # reduced by sweep) and the trailing edge leaves a low-pressure wake.
356    q_stag = 1.0 + mach**2 / 4.0 + mach**4 / 40.0     # stagnation / dynamic pressure
357    base_cd = 0.12 + 0.13 * mach**2                    # base-drag coefficient, M < 1
358    leading = 0.85 * q_stag * geom.fin_le_cos2
359    fin_frontal = geom.fin_count * geom.fin_thickness * geom.span
360    fin_pressure = (leading + base_cd) * fin_frontal / A
361
362    nose_pressure = 0.8 * geom.nose_joint_sin2         # 0 for smooth nose shapes
363    base = base_cd                                     # whole base area = A here
364
365    total = friction + fin_pressure + nose_pressure + base
366    return {"friction": friction, "fin_pressure": fin_pressure,
367            "nose_pressure": nose_pressure, "base": base, "total": total}

447    """Aerodynamic force and moment on the rocket, in body axes.
448
449    Parameters
450    ----------
451    geom : Geometry
452    drag_model : callable
453        ``drag_model(mach, reynolds)`` returning C_D.
454    v_air : numpy.ndarray
455        Velocity of the rocket relative to the air, body axes [m/s].
456    rho : float
457        Air density [kg/m^3].
458    sound_speed : float
459        Speed of sound [m/s].
460    viscosity : float
461        Dynamic viscosity of air [Pa s].
462    x_cg : float
463        Station of the current CG [m].
464    omega : numpy.ndarray
465        Body angular velocity [rad/s].
466
467    Returns
468    -------
469    force : numpy.ndarray
470        Aerodynamic force, body axes [N].
471    moment : numpy.ndarray
472        Aerodynamic moment about the CG, body axes [N m].
473    mach : float
474        Mach number [-].
475
476    Notes
477    -----
478    - Drag acts opposite ``v_air`` and passes through the CG.
479    - Normal force C_N = C_N_alpha sin(alpha) acts at the CP, at right angles
480      to the body axis, opposite the cross-flow. Linear (Barrowman) theory,
481      so it is only accurate for small angles of attack (below about 10 deg).
482    - Pitch damping: rotating at rate w adds a local cross-flow w * d at
483      distance d from the CG, so each component (nose, fins) contributes
484      -q A C_N_alpha_k d_k^2 w / V.
485    - No roll moments: the fins have no cant.
486    """
487    speed = sqrt(v_air[0] ** 2 + v_air[1] ** 2 + v_air[2] ** 2)
488    zero = np.zeros(3)
489    if speed < 1e-9:
490        return zero, zero.copy(), 0.0
491
492    mach = speed / sound_speed
493    reynolds = rho * speed * geom.length / viscosity
494    q_area = 0.5 * rho * speed**2 * geom.reference_area   # dynamic pressure x area [N]
495
496    force = -q_area * drag_model(mach, reynolds) * v_air / speed
497
498    cross = sqrt(v_air[1] ** 2 + v_air[2] ** 2)            # cross-flow speed [m/s]
499    cn_fins = fin_normal_force_slope(geom, mach)
500    moment = np.zeros(3)
501    if cross > 1e-12:
502        alpha = atan2(cross, v_air[0])                     # total angle of attack [rad]
503        cn_alpha = 2.0 + cn_fins
504        x_cp = (2.0 * geom.nose_cp + cn_fins * geom.fin_cp) / cn_alpha
505        normal = q_area * cn_alpha * sin(alpha)            # size of normal force [N]
506        f_normal = np.array([0.0, -normal * v_air[1] / cross, -normal * v_air[2] / cross])
507        force = force + f_normal
508        arm = np.array([x_cg - x_cp, 0.0, 0.0])            # CG to CP, body axes [m]
509        moment = cross3(arm, f_normal)
510
511    # Pitch and yaw damping (body y and z rates only).
512    damping = (q_area / speed) * (2.0 * (geom.nose_cp - x_cg) ** 2
513                                  + cn_fins * (geom.fin_cp - x_cg) ** 2)
514    moment[1] -= damping * omega[1]
515    moment[2] -= damping * omega[2]
516    return force, moment, mach
